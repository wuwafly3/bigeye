# MMD 模型放置说明

角色详情页使用 three.js 的 MMDLoader 渲染 MMD 模型（支持 `.pmx` / `.pmd`，
以及 `.vmd` 动作文件）。

## 方式一：放入仓库（站内直接加载）

1. 将模型**整个文件夹**（包含 .pmx 与全部贴图，保持原有相对路径结构）放入：
   `public/models/<角色id>/`，例如 `public/models/apollo/阿波罗.pmx`
2. 在 `src/data/characters.json` 对应角色中填写：

```json
"model": { "path": "models/apollo/阿波罗.pmx", "scale": 1 }
```

3. 可选：把 `.vmd` 动作文件放在同一目录，详情页可加载播放。

## 方式二：浏览者本地加载（不上传模型）

角色详情页提供"从本地文件夹加载"按钮：访问者直接选择自己电脑上的模型
文件夹（整个文件夹，含贴图），网站在浏览器内离线渲染，模型文件不会上传。

## ⚠️ 版权提醒

MMD 模型（尤其是官方或社区作者制作的模型）通常附带严格的使用条款
（readme.txt），很多**禁止再分发**。将模型文件提交到公开仓库前，请务必
确认模型作者允许再分发；不确定时请使用"方式二"本地加载，仓库中只保留
角色数据与截图。
